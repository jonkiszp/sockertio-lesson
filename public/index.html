Emisja zwrotna (Unicast)

Wiadomość trafia wyłącznie do klienta, który wywołał zdarzenie. Idealne do odpowiedzi na zapytania, potwierdzeń i prywatnych komunikatów. 

// Serwer:
socket.emit('odpowiedz', { ok: true });
socket.broadcast.emit()

Rozgłoszenie (Wszyscy oprócz mnie)

Wysyła zdarzenie do wszystkich podłączonych klientów z wyjątkiem nadawcy. Kluczowe przy powiadomieniach o dołączeniu czy pisaniu. 

// Serwer:
socket.broadcast.emit('powiadomienie', data);
io.emit()

Globalny Broadcast (Do wszystkich)

Rozsyła komunikat do absolutnie każdego podłączonego gniazda (włącznie z nadawcą wiadomości). 

// Serwer:
io.emit('ogolny_alert', { tresc: '...' });
io.to(pokoj).emit()

Pokoje (Rooms / Channels)

Komunikat trafia tylko do gniazd, które wcześniej wywołały socket.join(room). Podstawa pokojów rozmów, gier i subskrypcji. 

// Serwer:
io.to('programowanie').emit('nowy_kod', data);
Ack Callback

Wzorzec Żądanie-Odpowiedź (RPC)

Socket.io pozwala przekazać funkcję zwrotną jako ostatni argument. Serwer wywołuje ją z danymi zwrotnymi, symulując zapytanie REST w kanale WebSocket! 

// Klient:
socket.emit('zapisz', dane, (odpowiedz) => {
  console.log('Odebrano ACK:', odpowiedz);
});
REST → Socket.io

Emisja z zewnętrznego żądania HTTP

Wysyłamy tradycyjne żądanie POST /api/broadcast do serwera Express, a serwer natychmiast rozsyła je do wszystkich klientów przez Socket.io. 

app.post('/api/broadcast', (req, res) => {
  io.emit('system:alert', req.body);
  res.json({ ok: true });
});
